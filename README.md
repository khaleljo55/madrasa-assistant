# المساعد الإداري

برنامج لنظام ويندوز لتنظيم العمل الإداري في المدرسة: المهام، والتقويم، وسجل غياب المعلمات (فارس)، ومتابعة دخول الحصص مع رسائل الشكر، والإشراف على الفسحة، والأيام العالمية والوطنية، والزيارات، ومكتبة المعرفة، والمصحف (جزء تبارك وعمّ)، والأدوات المساعدة.

## التثبيت

1. افتح صفحة **Releases** في هذا المستودع.
2. نزّل أحدث ملف `Madrasa-Assistant-Setup-x.x.x.exe`.
3. انقر عليه مرتين واتبع خطوات التثبيت. يظهر اختصار «المساعد الإداري» على سطح المكتب.

> عند ظهور تحذير ويندوز الأزرق: «مزيد من المعلومات» ← «التشغيل على أي حال» (البرنامج غير موقّع رقمياً).

## التحديث

كل تعديل يُرفع إلى الفرع `main` يُبنى تلقائياً، ويظهر ملف تثبيت جديد في Releases. تثبيت الإصدار الجديد فوق القديم يحافظ على البيانات.

## البنية

| المسار | المحتوى |
|---|---|
| `app/` | الواجهة كاملة (HTML وCSS وJavaScript) |
| `main.js` | تشغيل البرنامج، والتنزيلات، والإملاء الصوتي |
| `preload.js` | الجسر الآمن بين الواجهة وويندوز |
| `.github/workflows/build.yml` | البناء التلقائي لملف التثبيت وفحصه |
